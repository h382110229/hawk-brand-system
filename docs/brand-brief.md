# HAWK — 品牌简报 (Brand Brief)

> 版本：v1.0 · 定稿待确认
> 日期：2026-07-23
> 来源：Hawk + Hermes Agent 协作品牌梳理

---

## 1. 品牌定位

| 维度 | 定义 |
|------|------|
| **品牌名** | **HAWK**（全大写，核心标识） |
| **本质** | 个人技术品牌，未来可扩展为对外服务品牌 |
| **核心受众** | 技术同行（开发者/架构师）、科技圈关注者 |
| **一句话定位** | 一个技术人员的数字身份系统 |

---

## 2. 调性关键词

| 关键词 | 含义 |
|--------|------|
| **轻奢** | 质感精致但不浮夸，克制的高级感 |
| **现代** | 干净利落，当代设计语言，不过度装饰 |
| **智能** | 技术感、精密感，暗示工程能力 |

### 拒绝的气质
- ❌ 太花哨（赛博朋克、霓虹、过度动效）
- ❌ 太传统（企业蓝、银行风、老派衬线体）

### 视觉参考
- **Google Material Design** — 干净、克制、色彩明快、友好的技术感

---

## 3. 视觉元素

### 3.1 核心：HAWK 四字母交织

- **H · A · W · K** 四个字母以几何方式交织/嵌套
- 纯直线、锐角、无曲线 — 对应"精密/现代"调性
- 字母结构本身就是品牌灵魂，**与鹰/鸟类无关**
- 允许字母自然形成盾形轮廓，但**不要求固定盾牌边框**

### 3.2 Logo 简化梯度

| 级别 | 场景 | 形态 |
|------|------|------|
| **Full** | 网站 header、文档封面、大型展示 | 完整 HAWK 交织结构 + 可选边框/容器 |
| **Mark** | 社交头像、水印、favicon | 仅 HAWK 交织几何（去容器） |
| **Icon** | App icon、16×16 favicon | HAWK 最小可识别子结构 |
| **Wordmark** | 文字场景 | "HAWK" 纯文字标（几何无衬线字体） |
| **ASCII** | 终端、代码注释 | 等宽字符艺术版本 |

### 3.3 品牌名扩展体系

| 子品牌 | 场景 | 示例 |
|--------|------|------|
| **HAWK** | 核心标识、署名、通用 | GitHub 头像、邮件签名 |
| **Hawk Studio** | 创意/设计/开发相关 | 个人网站、作品集 |
| **Hawk NAS** | 存储/家庭服务器 | NAS 控制台 UI |
| **Hawk [Service]** | 未来可扩展 | 按需衍生，保持 HAWK 前缀统一 |

> 规则：子品牌 = HAWK Mark + 服务名文字，服务名用正常大小写

## 4. 色彩系统

### 4.1 双模式并存

| 模式 | 主色 | 底色 | 使用场景 |
|------|------|------|----------|
| **Dark Mode** | 金属金 `#D4AF37` | `#0A0A0A` ~ `#121212` | 终端、深色 UI、夜间场景 |
| **Light Mode** | Google Blue `#4285F4` | `#FFFFFF` ~ `#F8F9FA` | 文档、对外展示、正式场合 |

### 4.2 Dark Mode 色板

| Token | 色值 | 用途 |
|-------|------|------|
| `hawk-gold` | `#D4AF37` | 主品牌色、Logo、重点强调 |
| `hawk-gold-light` | `#E8D48B` | Hover / 高亮状态 |
| `hawk-gold-dark` | `#B8941E` | 按下 / 深层状态 |
| `bg-primary` | `#0A0A0A` | 主背景 |
| `bg-secondary` | `#141414` | 卡片 / 面板背景 |
| `bg-tertiary` | `#1E1E1E` | 悬浮 / 弹窗背景 |
| `text-primary` | `#EAEAEA` | 主文字 |
| `text-secondary` | `#A0A0A0` | 次要文字 |

### 4.3 Light Mode 色板

| Token | 色值 | 用途 |
|-------|------|------|
| `hawk-blue` | `#4285F4` | 主品牌色、Logo、链接、按钮 |
| `hawk-blue-light` | `#669DF6` | Hover 状态 |
| `hawk-blue-dark` | `#1A73E8` | 按下状态 |
| `hawk-red` | `#EA4335` | 辅助强调（可选） |
| `hawk-yellow` | `#FBBC05` | 辅助强调（可选） |
| `hawk-green` | `#34A853` | 辅助强调（可选） |
| `bg-primary` | `#FFFFFF` | 主背景 |
| `bg-secondary` | `#F8F9FA` | 卡片背景 |
| `text-primary` | `#202124` | 主文字 |
| `text-secondary` | `#5F6368` | 次要文字 |

### 4.4 Logo 与模式的对应

- Dark Mode 环境 → 使用金色版 Logo
- Light Mode 环境 → 使用蓝色版 Logo
- 两套 Logo 结构一致（HAWK 交织几何），仅色彩不同

## 5. 字体方向

| 用途 | 风格 | 候选 |
|------|------|------|
| **Logo / Display** | 几何无衬线，直线感 | 定制 / 手工调整 |
| **Heading** | 中等字重无衬线 | Inter / Plus Jakarta Sans |
| **Body** | 高可读无衬线 | Inter / IBM Plex Sans |
| **Code** | 等宽 | JetBrains Mono / Fira Code |

---

## 6. Logo 使用规范

### 6.1 安全区
- Logo 四周留至少 **logo 高度 25%** 的空白

### 6.2 最小尺寸
- Full Logo：最小宽度 120px
- Mark（纯几何）：最小宽度 32px
- Icon：最小 16×16px

### 6.3 禁止用法
- ❌ 拉伸变形
- ❌ 添加投影/光晕（Logo 自身已有质感）
- ❌ 在复杂背景上使用（需加纯色底板）
- ❌ 更改非规定的配色方案
- ❌ 旋转 Logo
