# HAWK Brand System

个人技术品牌的视觉设计系统 — Design Token、Logo 规范、色彩体系、排版指引。

## 定位

**轻奢 · 现代 · 智能**

品牌名 HAWK，四字母几何交织为核心视觉元素。双色彩模式并存：Dark（金+黑）/ Light（蓝+白）。

## 目录结构

```
hawk-brand-system/
├── docs/
│   └── brand-brief.md          # 品牌简报（定位、调性、色彩、字体、使用规范）
├── tokens/
│   ├── color/
│   │   ├── dark.json           # Dark Mode 色彩 Token
│   │   └── light.json          # Light Mode 色彩 Token
│   ├── typography.json         # 字体系统 Token
│   ├── spacing.json            # 间距节奏 Token
│   ├── elevation.json          # 阴影 / 浮雕层级 Token
│   ├── motion.json             # 动画缓动 Token
│   ├── radius.json             # 圆角 Token
│   └── breakpoint.json         # 响应式断点 Token
├── assets/
│   └── logo-candidates/        # Logo 生成候选稿
├── .gitignore
└── README.md
```
