# HAWK Logo Round 5 — 设计方案说明

> 版本：v4 FINAL · 日期：2026-07-24

## 三个概念

### Concept 01: "Monolith" — 垂直 A·H/K·W 盾形堆叠
- A 顶峰 + H|K 中段 + W 谷底 → 自然形成盾牌轮廓
- 最佳 32×32 辨识度（盾形剪影最清晰）
- 适合社交头像、App icon

### Concept 02: "Forge" — 2×2 网格共享十字轴
- H(左上) A(右上) / W(左下) K(右下)
- 中心十字轴共享，Material Design 气质
- 结构最规整，工程感最强

### Concept 03: "Apex" — 水平共享笔触字标
- 继承 var3 方向：四字母水平排列共享笔触
- HAWK 四字母识别度最高
- 适合网站 header、品牌展示

## 共通特征
- 纯平面，纯直线，锐角，无曲线
- 45° 切角端头
- Dark: 金 #D4AF37 + 黑 #0A0A0A
- Light: 蓝 #4285F4 + 白 #FFFFFF
- 每个概念含 SVG + 1024px PNG + 32px 测试
