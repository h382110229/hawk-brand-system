# HAWK Logo — Antigravity 生成 Prompt 集

> 策略：减少硬性约束，给视觉方向和感觉，让模型自由发挥
> 所有 prompt 均为 Dark 版（金 #D4AF37 + 黑 #0A0A0A），结构确认后再出 Light 版

---

## Prompt 1 — 科技极简

```
Design a modern tech logo for the word "HAWK". The four letters H, A, W, K should merge into one compact geometric symbol. Think of how tech companies like Google, Stripe, or Linear design their logos — clean, minimal, instantly recognizable. Use straight lines and angular shapes. Gold on black. No illustrations, just pure typography as the logo.
```

## Prompt 2 — 字母徽章

```
Create a sleek monogram logo combining the letters H, A, W, K into an elegant intertwined emblem. Similar to luxury fashion monograms (Louis Vuitton, Chanel) but with a modern geometric twist — sharp angles instead of curves. The letters should share strokes and overlap naturally. Rich gold on deep black background. Bold, confident, minimal.
```

## Prompt 3 — 几何图标

```
Design a simple app icon for "HAWK". It should be a bold geometric shape that suggests the letters H A W K without spelling them out literally. Like how the Medium logo is just a bold "M" or the Beats logo is a lowercase "b" in a circle — iconic, abstract, memorable. Angular and sharp. Gold on black. Square canvas.
```

## Prompt 4 — 字标融合

```
A bold typographic logo where HAWK is written in a custom geometric sans-serif typeface. The letters are tightly spaced so they share vertical strokes — H's right bar becomes A's left leg, W's peaks touch A's base, K's left bar is W's right edge. Like a custom wordmark where the font IS the logo. Flat gold on black. No effects, just clean vector shapes.
```

## Prompt 5 — 负空间

```
Design a clever logo where the negative space between geometric shapes reveals the letters H, A, W, K. Think of the FedEx arrow or the NBC peacock — hidden letters within a simple geometric form. Angular, modern, gold on black. The overall shape should be clean and bold enough to work as a tiny favicon.
```

## Prompt 6 — 参考你的原图

```
A polished geometric logo mark on a black background. The letters H, A, W, K are interlocked into a shield-like angular emblem. Each letter shares edges with its neighbors, forming one cohesive golden symbol. The style is premium and technical — think high-end tech brand identity, not a sports team badge. Metallic gold, clean lines, centered on black.
```

---

## 使用建议

- 每个 prompt 单独生成 2-3 张，挑最好的
- 不要一次加太多限制，先看模型的"自由发挥"结果
- 哪个方向最接近你的感觉，再在那个方向上微调
- 结构确认后再统一出 Light 版（把 "gold on black" 改成 "blue on white" 即可）
